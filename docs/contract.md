# 多台站到时分组契约

这是已提取到时记录的有限分组数据API，不是完整地震学事件定位器。stations为1..100项唯一id/lat/lon，lat[-90,90]、lon[-180,180]度；events为1..2000项唯一到时id、既有station、phase=P或S、time。time和非负window使用同一调用方自定时间单位，十进制字符串精确转Fraction；输出为整数或n/d字符串。所有字段严格检查。

全部到时先按(time,id)排序。从第一条开始，事件anchor固定为该组最早到时；后续到时与anchor差<=window时加入，否则开始新组。不以相邻到时的传递闭包无限延长组，也不按距离传播修正。同台站同相位不同id允许，作为独立输入保留；相同到时id拒绝。台站位置仅保留输入校验，不参与传播模型。

输出e1/e2等编号随排序后的组顺序产生，只是本次数据集身份，不保证添加早期到时后跨版本稳定。保留到时id/台站/相位/精确时间和相位计数。不是天气应用、预约或物理模拟；`process` 本身不推断震源、震级、P/S传播时延或地理事件真实性。候选旅行时诊断和下游准入是独立的纯计算 API，见 [候选震源位置契约](location-contract.md)；它不改变本文件定义的归并行为。输入错误抛ValueError，整个计算完成后才能发布新结果。
