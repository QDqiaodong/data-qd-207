# 本地波形复核目录契约

在 [多台站到时分组契约](contract.md) 之上扩展的**只登记引用**的本地复核目录。
目录不传输、不解码、不删除任何波形文件，不做震源定位；它保存的全部是
台站、原始块、采样区间、到时、校时分段、归档回执和下线决定这类引用数据。

## 生命周期与并发

- `create_review(path, data, first_version)` 建档并提交首版校时；目录已存在时报错。
- `open_review(path)` 重开既有目录，重放提交日志后返回同形态句柄。
- 本地**单写者**：目录内 `LOCK` 用进程级文件锁强制，第二个并发打开者报错；
  句柄可作上下文管理器使用，`close()` 释放锁，之后可在新进程重开。
- 建档后台站、采样域、原始块、到时、归并窗 `window` 与回看参数 `pre/post`
  全部不可变；只有校时版本、归档回执、下线决定可以追加。

## 建档输入（沿用 process 口径并收紧）

- `stations`：1..100 项，字段与旧接口一致，仅用于校验。
- `events`：1..2000 项，字段沿用旧接口；本目录中 `time` 是**台站本地采样刻度**，
  必须为整数（`bool` 不是整数），且落在该站采样域 `[0,N)` 内；旧 `process`
  入口仍接受十进制小数字符串，互不影响。
- `domains`：每个台站一个半开整数区间，必须是 `[0,N)` 且 `1 <= N <= 10^9`。
- `blocks`：1..2000 个原始块，全档唯一块 ID，登记台站与域内非空半开整数区间；
  同站块不得重叠，可以有空洞。
- `window`：精确十进制，非负；`pre >= 0`、`post > 0`，同为精确十进制。
- ID 仍匹配 `[A-Za-z0-9_:-]{1,64}`；所有整数边界拒绝布尔值；输入错误抛
  `ValueError` 且不改目录。

## 校时版本与取样计划

- `submit_clock(version)` 追加版本。版本有独立 ID 空间；每站 1..128 个
  半开整数分段，互不重叠、无空洞地完整覆盖采样域，每段带精确十进制 `offset`，
  本地刻度 `t` 的统一时间为 `t + offset`。允许统一时间出现跳跃或重叠；
  到时不会因此被丢弃，也不允许任选一段。
- 计算顺序：先把每个到时按其**本地刻度**所在分段换算成统一时间，再复用旧
  `process` 的口径——按 `(统一时间, 到时 ID)` 排序、固定组首 anchor、
  `time - anchor <= window` 的边界规则归并、保留同样的事件证据。统一时间用
  `Fraction` 精确计算，输出为精确十进制（除不尽时为 `n/d`），不舍入到采样点。
- 事件编号 `e1..eN` 只在校时版本内有意义；每个事件只要求证据中实际出现的台站。
- 每个证据台站需要满足 `anchor-pre <= t+offset < anchor+post` 的**整数本地
  采样点**，逐段换算为半开整数区间交付：
  - 下界取 `ceil(anchor-pre-offset)`、上界取 `ceil(anchor+post-offset)`，
    再与分段区间求交；不枚举、不逐点存储采样点。
  - 不同分段即使映到相同统一时间也各自保留区间；跨段相邻的区间不合并，
    不填入中间没有命中的采样点；区间可包含未录得块的采样点（查询时标缺失）。
- `read_plan(version_id=None)` 返回指定版（默认当前版）的固定证据与本地范围；
  计划文件一经写入不可变，新版本、新回执或下线都不改写历史计划。
- 新校时即使产生无法取得的片段也允许生效，事件不允许被隐去。

## 归档回执

- `register_receipt(receipt)` 登记回执，回执 ID 独立编号。回执指向**指定校时版
  内的指定事件**、一块原始块和一个非空本地采样区间；区间必须既完全属于该块，
  又完全属于该事件在该块所属台站的所需范围（可落在其中一段所需区间内）。
- 首次登记时原块必须仍在线；允许引用历史版本的事件，不能拿当前同名事件替
  历史事件验收。
- 已登记片段可服务于任意版本或事件，但只覆盖**同一块内的同一原始采样点**；
  相同事件号、相同统一时间或同块已有部分归档都不会扩大覆盖。多个回执允许重叠。

## 下线决定与当前回看来源

- `request_offline(request)` 带独立请求 ID 与块 ID。仅当该块被**当前版任意
  事件**需要的每个采样点都已有归档覆盖时才批准；当前版没有任何需求的块可以
  直接批准。
- 批准后整块立即视为不可读取且不可重新上线；已有归档引用继续有效。更晚的校时
  若需要该块未归档片段，查询如实返回缺失，既不引用已下线块也不倒改决定。
- 对已下线块的新下线请求（其他 ID）与新归档回执一律拒绝。
- `query_sources(version_id=None)` 给出整个计划逐片段的确定来源：
  - `archive`：能提供该片段的回执 ID；多个回执重叠时取**字典序最小**者；
  - `online`：仍在线的原块 ID；
  - `missing`：无任何来源，包括采样域内的块空洞和已下线块的未归档片段。
  同一块内三种片段可同时区分，不提供站级或事件级的粗粒度可用标志。
- `block_status(block_id)` 返回 `online`/`offline`。

## 幂等、重放与原子性

- 校时版本、回执、下线请求、数据集发布请求四类 ID 空间互相独立；每类中**成功
  ID 的等价重放**原样返回首次应答，不产生新变更，也不按当前条件重新审核。
- 相同成功 ID 携带不同内容、非法输入或不满足业务前置条件的请求都抛
  `ValueError` 且不改目录；被拒绝的请求 ID 未被占用，可以重试。
- 校时分段的输入顺序、等值十进制的不同写法（如 `1.0` 与 `1`、`-0` 与 `0`）
  经规范化后不构成冲突；十进制字符串仍须满足旧 `number` 的格式与位数口径。
- 持久化布局：
  - `catalog.json`：建档后不可变的引用目录；
  - `plan-v<序号>-<版本ID>.json`：每版一份不可变取样计划；
  - `journal.log`：顺序追加日志，每条决定以独立 JSON 行写入并 fsync，随后写入
    `COMMITTED` 标记并再次 fsync；
  - `state.json`：journal 的派生缓存（当前版指针、回执、下线块），用临时文件
    原子替换；
  - `LOCK`：单写者文件锁。
- 决定的生效边界是 journal 的 `COMMITTED`：
  - 写 JSON 行后、写标记前中断：重开时整条决定回滚，块仍在线、请求 ID 未占用；
  - 标记已落盘但调用方未收到应答：重开后用同一 ID 重放只能取回原决定，
    journal 中不会出现第二条；
  - `state.json` 缺失或停留在旧状态：重开以 journal 为准重放并无条件重写缓存。
  因此“当前下线状态”与成功应答要么一起可见，要么都不可见，不存在半个决定。

## 数据集发布账本（训练/盲测隔离）

在复核目录上可继续使用 `preview_release`、`publish_release` 与
`read_release`（另有 `get_release` 的 `None` 查询语义和若干近义方法名）。
发布账本以台站和整数本地采样刻度识别原始样本，把全部候选事件按区间重叠传递
分组，并将批准组的训练/盲测用途原子写入同一条 journal release 记录。完整
API、预览字段、清单契约、幂等等价性和崩溃重开行为见
[数据集发布账本契约](dataset-release.md)。

## 样本级特征血缘与交付凭证（只登记依赖）

在同一目录上还可使用 `capture_waveform_input`、`register_window_feature`、
`record_sample_defect`、`feature_health`、`issue_feature_certificate`、
`read_feature_node`、`read_feature_certificate` 与
`check_feature_certificate`，把滑窗特征的实际归档来源、窗口依赖、副本/物理
两类缺陷和受当前血缘约束的交付凭证固定下来。副本缺陷按片段接入
`query_sources`、`request_offline` 与 `publish_release`，物理缺陷则在首次
发布时整笔拒绝且不改变副本可读性分类。完整字段、传播公式、容量上限与
重开语义见 [特征血缘与交付凭证契约](feature-lineage.md)。

## 明确不做的事

不传输/解码/改写/删除波形数据，不做震源定位、震级或走时建模，不推断事件的
物理真实性；目录内没有波形字节，只有可由调用方据此取数的引用与决定。

## 跨版本稳定事件目录身份（只读扩展）

`e1/e2/…` 仅在单个校时版本内有效。需要跨版本稳定身份与拆分/合并谱系的下游，
使用独立的只读 API `reconcile_event_catalog(...)`；它只经 `list_versions()` 与
`read_plan()` 读取本目录，不新增、不改写任何目录文件，也不关闭调用方句柄。
规范键、`ceN` 分配、全局一对一继承选择、谱系 schema 与拒绝边界见
[事件目录身份契约](event-catalog.md)。
